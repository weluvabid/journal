# Architecture decisions

These records cover decisions that changed the shape of Frontend Atlas. Some are technical, some
are product boundaries, and some started with a very simple motivation: I did not want another
thing to maintain.

Each one explains the problem, the choice, and the trade-offs. If a decision changes, add a new
record so the old reasoning does not disappear from the project's history.
