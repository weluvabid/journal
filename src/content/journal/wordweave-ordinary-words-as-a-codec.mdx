I started WordWeave after running into a chat filter that replaced messages with `#####`. It maps selected terms to ordinary four-word phrases while preserving punctuation, whitespace and casing. The mapping is reversible, and the vocabulary is public, so anyone with it can decode the phrases.

The budget is the phrase space. Each of four positions picks from 64 words.

`64⁴ = 16,777,216`

Each position contributes six bits if the choices are uniform and independent. Three positions give `64³ = 262,144` phrases; four give `64⁴ = 16,777,216`, a 64-fold increase. The same 64 reserved phrases therefore occupy 64 times less of the four-word space. That's the combinatorial model. The corpus scan checks how the chosen vocabulary behaves in real text, where word frequencies and sentence positions are far from uniform or independent.

The scanner resets for each document, so phrases never span file boundaries. The checked-in corpus is 135 documents and 643,164 tokens. Technical docs, literature, conversation samples. The scan on record found zero reserved-phrase collisions in that set.

If a reserved phrase appears, `findCodewordCollisions` reports the phrase and its offset in JavaScript UTF-16 code units. That matters because decoding is exact: a reserved phrase is indistinguishable from encoded content. Consequently, `decode(encode(text)) === text` only holds when the input contains no reserved phrase. The collision check exposes that condition before encoding.

```ts
import { decode, encode, findCodewordCollisions } from 'wordweave';

const encoded = encode('A selected source term, please.');
const original = decode(encoded);
const collisions = findCodewordCollisions('ordinary text to inspect');
```

`VOCABULARY_VERSION` is the protocol. Change a mapping and an old phrase means something else, or nothing. Decode with the version you encoded with. There's no compatibility layer hiding in the words.

I also tried the phrases in the platform chat that inspired the project. That test only tells me how the phrases behaved in that chat at the time. The vocabulary is public, so anyone who has it can decode them; WordWeave provides no confidentiality or authentication.
