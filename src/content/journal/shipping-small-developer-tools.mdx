The tools I finish are the ones I can say in one job. Take this input. Do this inspection or transform. Hand back something you can trust. JSON+ is JSON, not a data platform. CSV Doctor is CSV, not a spreadsheet with opinions about charts. An extension makes sense when the page is already in the browser and the work can stay there.

I kept circling a small bundle instead of one big app. "What large thing could this become" is a fun question and a bad one. The useful question is which annoyance shows up every week, and where the existing tool makes it worse.

Narrow also caps the mess. Fewer formats, fewer permissions, fewer integrations, fewer "import your workspace" tickets. If the first screen wants an account before it does the one job, the advantage of being small is already gone.

Local is a feature when the alternative is uploading someone's file to a server I then have to run. Less latency. No user-data backend on the critical path. It is not a security badge. Content scripts, clipboard, parsing, memory limits, host permissions. Those are still the product. Say what gets read and where it runs. Sync, shared history, a team workspace. Those show up the day a server does. I don't pretend they're included.

Someone pays when the tool removes a repeated annoyance or stops a dumb mistake. A low one-time price lowers the flinch. It doesn't create the want. A demo of the saved minute, docs that match the behavior, and some way for people to find it matter more than the number on the button.

A lifetime licence is a support contract with a friendly name. What updates are in, whether the next product is a separate buy, how a licence gets checked. Building an entitlement system before there are customers is how a tiny utility grows a billing department it doesn't need.

First cut, for me: the core path, errors a person can act on, tests around the ugly inputs, a short README, a demo, and a sentence about what I won't support yet. The quality bar stays. The scope stays rude.

*Example I'd add:* one before/after of the actual job. A JSON value with a cycle, or a broken CSV row, and the output or error. Not a feature list.
